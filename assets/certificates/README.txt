Certificates Directory
======================
Place certificate files (images or PDFs) in this directory.

To link a certificate to the portfolio:
1. Copy your certificate file here (e.g. epit-internship.pdf or aws-cert.png).
2. Open script.js.
3. Locate the CERTIFICATES array and update the `file` field for that certificate:
     file: "./assets/certificates/your-filename.pdf"
4. If you have an online verification URL, set the `link` field:
     link: "https://your-verification-url.com"
